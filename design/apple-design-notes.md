# Dream Diary · design revision

The design follows Apple's Human Interface Guidelines as principles for the existing Android app. It uses Android's system type, permissions, accessibility semantics and navigation behavior.

References reviewed on 22 October 2026:

- [Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles): purpose, agency, familiarity, simplicity, craft and delight.
- [Layout](https://developer.apple.com/design/human-interface-guidelines/layout): hierarchy, alignment, edge-to-edge content, safe areas and adaptation.
- [Typography](https://developer.apple.com/design/human-interface-guidelines/typography): legibility, restrained type families and a consistent hierarchy.
- [Motion](https://developer.apple.com/design/human-interface-guidelines/motion): brief, purposeful transitions and support for system animation preferences.

## Applied decisions

- Keep the notebook as the writing surface. Paper, aligned rules, the center fold and a faster page turn reinforce the physical interaction.
- Reserve Lora for dreams and remembered content. Use the system sans serif for navigation, settings and section hierarchy. Lucidity is a small checkbox beside the page number, with a full-height touch target.
- Use charcoal text, an ivory page, neutral grouped surfaces and one ink-blue action color. A lucid dream uses soft lavender paper, fading back to ivory when unmarked. Each has a specific role; the accent identifies interactive controls.
- Put Dreams, Practice and New dream in a consistent bottom control group. Keep page navigation separate from app navigation.
- Replace the practice-card catalogue with a primary reality check and grouped morning, evening and reference tools.
- Reveal guide options, supporting research and the full text of tips on demand. Preserve all underlying practices and settings.
- Replace the reminder frequency slider with an exact stepper. Put the schedule, repeat days, evening reminder, sound and vibration in distinct sections.
- Show actual timer progress and keep start, pause, next and completion actions in the same guide card.
- Keep writing and control surfaces full screen in both orientations, with bounded reading widths and two-column practice tools where space allows.

No diary or practice storage format changes are part of this revision.
